README - Zyxel Firmware Source Package
======================================

Overview
--------
This package provides the source code and build tools related to the firmware for Zyxel products,
in compliance with applicable open-source license requirements.

OpenWrt Version
---------------
The firmware and associated tools are based on **OpenWrt 21.02**.  
OpenWrt 21.02 source code can be downloaded from:  
https://github.com/openwrt/openwrt/tree/openwrt-21.02

Folder Contents
---------------
1. src/
   - Contains the source code that must be released under GPL requirements.
   - Includes the actual GPL-related code used in the Zyxel firmware.

2. toolchain.tar
   - The toolchain required to build the firmware.
   - Fully compatible with OpenWrt 21.02.

Summary
-------
This package includes shared GPL source code and build tools.
All materials are provided in compliance with applicable open-source license obligations.
All packages and toolchains are based on OpenWrt 21.02 series.
